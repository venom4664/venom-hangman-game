# Venom Hangman — Educational Project

A Streamlit Hangman game built for learning Python fundamentals and Streamlit UI development.

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

Open the local URL shown by Streamlit, normally:

`http://localhost:8501`
